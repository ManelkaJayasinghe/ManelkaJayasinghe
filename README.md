## 🚀 Featured Projects

### ☀️ Dynamic Reconfiguration of Single-Phase PV Inverters
**Final-Year Research Project**

A simulation-based study exploring dynamic reconfiguration of single-phase PV inverters to help minimize voltage violations in a distribution feeder.

- Investigating feeder voltage profiles and voltage-limit violations
- Considering inverter capacity, connection phase, and physical location
- Developing and evaluating a control approach for phase reconfiguration and voltage support

**Focus:** Distribution networks · Solar PV integration · MATLAB/Simulink

### 🐘 Intelligent Electric Fencing for Animals
An embedded computer-vision project designed to identify animals and trigger the corresponding fence-zone response.

- Trained a YOLOv5n object-detection model using a labelled image dataset
- Integrated Raspberry Pi, Arduino, serial commands, relays, and a buzzer
- Explored machine vision as part of an animal-detection and alert system

**Focus:** YOLOv5 · Python · Raspberry Pi · Arduino · Computer Vision

### ⚡ Rocker Breaker Switch Improvement
**LECO Training Project**

Investigated slow contact separation in a low-voltage rocker breaker associated with insufficient spring force, and considered increasing spring stiffness/preload as an improvement.

**Focus:** Low-voltage switching · Mechanical operation · Troubleshooting

### 🏢 Electrical Installation Design
Worked on an electrical installation design exercise for a seven-storey building using AutoCAD and DIALux, including load calculations and protection planning.

**Focus:** Electrical design · Load calculations · Lighting design
